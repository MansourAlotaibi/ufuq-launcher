## Scope and evidence rules

The authoritative baseline is the actual owner-named MansourTV source reporting version **2.8.5 / code 15**, read without modification. The comparison covers all 77 original Java files, settings resources/defaults, preferences, manifest, native navigation and lifecycle paths. All 77 Java files remain in public Ufuq; namespace/identity changes are normalized separately from functional changes. The final inventory has **55 normalized-identical files, 22 changed files and 8 public additions**; see [file hashes](FUNCTIONAL-SOURCE-INVENTORY.json). A file inventory records hashes, rather than publishing personal configuration or raw private diffs.

“Original behavior” below distinguishes source-defined behavior from the owner's accepted stable installation. The protected installation was **not** used for destructive A/B tests, settings changes, cache manipulation or force-stop experiments. Its private preferences were not extracted or copied. A source match does not prove runtime equivalence.

RC2 at audit entry is `1ee2a0c6a43af8de78d89edc7cdc032aea72864b`. Earlier functional restoration was `680a5fa`; visual correction was `1ee2a0c`. The final correction remains on the development branch. No main update/push/publication is authorized here.

Classifications: **R** regression relative to the original experience; **I** valid improvement (including an inherited defect safely corrected); **C** justified device/public-distribution adaptation; **U** unnecessary change simplified/reverted; **V** unverified behavior. Each changed behavior has one primary classification; test limitations are recorded separately.

Evidence: **TV** actual Nobel Android 4.4.4/API 19 interaction/capture; **F** deterministic framework/unit test (not hardware proof); **S** direct original-source comparison; **P** explicitly identified earlier RC2 physical evidence. Private screenshots, logs, build-specific action ledger and owner report are excluded from Git. D-pad testing uses injected ADB events, never a claimed physical remote press.

## Corrections and acceptance boundary

Confirmed regressions are fixed in source and regression tests, then exercised on the separate public installation where safely possible. Inherited defects are labeled as such; they are not used to claim the owner's original installation was unstable. Improvements and compatibility adaptations are retained rather than broadly reverting RC2.

The matrix intentionally does **not** equate an unchanged implementation or a passing framework test with a verified real-device result. Unverified rows remain explicit limits on any claim of complete functional/stability certification. Safe test results, final build counts, exact commit/APK hashes, runtime captures and protected-state comparisons are recorded in the owner-only report.

No push, main update, release creation, visibility change, personal-app data change, default-HOME selection, accessibility grant, stock-launcher disable or inherited installer execution is part of this audit.

## Current verification summary

The required release command passes **295 tests with 0 failures/errors/skips**, release lint **0 errors / 147 warnings**, and `assembleRelease`. Tests include API 19/28/34 framework cases. The test count is supporting evidence, not the device acceptance criterion.

Actual native-TV evidence includes:

- Save a nonpersonal greeting, return to Home, force-stop only public Ufuq behind the original Settings screen, reopen and observe persistence.
- All four Gregorian/Hijri combinations, minimal information mode, city and Hijri-adjustment changes, then restore the original public choices.
- Short Hadith and long Quran reading, pointer access, complete copyright notice, Back to reading and Back to Home; the final long preview uses an explicit measured excerpt without the former half-cut fourth line.
- Add a temporary Downloads shortcut, restart, pick/move/drop it across a favorites page boundary, restart with the new order, restore the order and remove the test shortcut. Original membership/order were compared to the audit-entry snapshot.
- Six Arabic/English × Classic/Midnight/Coast Home cases with both prayer and football present. Change Hilal/Nassr/Real Madrid, open actual native provider-detail dialogs, restart on Hilal and return to the right team. System-default language returns to the device's Arabic context without changing the global language.
- Fixed-image and dimming changes survive public-process restart. A passive 92.76-second foreground observation with the one-minute interval shows a changed wallpaper; restore the normal fifteen-minute interval afterward. This does not certify overnight operation.
- Source-calculated prayer times visibly change when selecting Jeddah and return to Riyadh. The capture sequence also crosses the actual Asr time; the next-prayer highlight advances to Maghrib without changing the device clock.

Provider outages/forced time rollback, physical remote presses, modern hardware, password/reconnection, accessibility-helper enablement, optional external configurations, screensaver takeover and long-duration/low-memory stress remain outside the verified device claims. Controlled expired-cache, HTTP 503, wrong-team and future-clock cases are deterministic framework tests only. KitKat does not expose the targeted trim-memory shell command on this TV; no global memory-pressure experiment was substituted.
