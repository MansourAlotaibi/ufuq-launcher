# Screenshot credits, privacy and provenance

## What these images are

These are21 promotional derivatives of genuine 1920×1080 Nobel API 19 Ufuq RC2 captures from 2026-10-30. Every output retains the complete 16:9 frame and original layout. Opaque masks hide private names, SSID text, private app icons/labels and selected sensitive catalog entries. They are not part of Ufuq UI. No crop, scale, replacement demo name, replacement icon, compositing, inpainting or invented screen is used. The generic greeting and common app icons are original pixels. Masked entries must not be described as empty slots.

No new TV interaction or runtime test occurred during gallery preparation. Previous owner-reported physical checks and injected tests are separately documented in the final audit. No source original is redistributed or modified. The accepted application source is 7091b90; captured APK SHA-256 is 17fe36e3e416f1f33627a7d0715846adbe5158d1c5ce426451b1c3b0e893f766. The documentation branch does not change application source, UI geometry, package/signing, installed launchers or HOME.

[PROVENANCE.json](PROVENANCE.json) records input/output hashes, neutral source capture IDs, output dimensions, exact mask rectangles/categories and byte sizes. It deliberately excludes raw screenshots/XML/logs, actual redacted values, credentials, network names/addresses, unique device IDs and absolute local paths. Original metadata is discarded; PNGs contain only public component notices/source/edit disclosures. Pixel identity outside masks, mask opacity and unchanged source hashes are checked. Lossless PNG optimization retains readability and exact pixels; the image set is about 17 MiB. Owner visual review is still required before any upload.

## Privacy decisions

- Home: keep real clock, dates, actual greeting words, reflection, rail, navigation and the complete dock. Mask the saved personal name and Wi-Fi label. Mask both the icon and label of private app entries, preserving the real tile geometry. Recognizable common apps are retained as explicitly requested.
- Library: five private/tool entries are masked. Public app icons/names remain; no fake catalog has been assembled. KitKat's popup accessibility hierarchy omitted this catalog, so its fixed cell masks were visually reviewed rather than falsely claimed as XML coverage.
- Wi-Fi: mask every visible SSID, including a partial bottom row, and connected-network status. Preserve actual signal/security controls. The image is not evidence of a new connection test.
- Reading dialogs: retain all canonical text, citations and source/license controls. Background privacy masks are clipped around the real dialog, so they do not obscure its content.
- Launcher picker: private launcher names masked. The real picker was cancelled; no protected launcher was opened and no default HOME change is claimed.
- Football group dialog: mask the saved personal name in the background. Fixture data is a capture-time snapshot, not a guarantee of live/current results.

## Language and evidence limits

Arabic and English galleries cover the same 14 feature groups. Native English captures exist for the three themes, Home/dock, Move, font choices and Settings. The current library, reading, sunset, team-group, wallpaper-control, Wi-Fi and launcher-picker captures are Arabic and are labeled as such when shared in the English gallery. Their captions are translated, their pixels are not. Religious text remains Arabic in both UI languages by design; third-party app labels can follow the installed app/system language. No missing English screen is fabricated. See [English coverage](COVERAGE_EN.json) and [Arabic coverage](COVERAGE_AR.json).

These screens do not by themselves prove timed rotation, persistence, live networking, completed launcher switching or a physical key press. Appropriate evidence/limits are in the existing audit. API 19 hardware does not prove other firmware/API levels; standard Inputs are unavailable on this device and are documented rather than invented in an image.
