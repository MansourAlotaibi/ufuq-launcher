# مشغّل أفق

[English](README.md)

مشغّل Android TV بلغة Java، يدعم API 19 والتنقل بأزرار الاتجاهات والعربية والإنجليزية.
الإصدار المحلي المرشح: **1.0.0-rc2**. توجد نسخة محلية موقّعة بهوية عامة مستقلة؛ لم يُنشر الإصدار بعد.

اختر المظهر من إعدادات المشغّل: الكلاسيكي الذهبي، منتصف الليل الفضي، أو الساحل التركوازي.
اختيار الخلفية ووضعها الثابت أو العشوائي مستقل عن المظهر.
توجد صورتان فوتوغرافيتان للمناظر الطبيعية من الملكية العامة، مع توثيق المصدر والحقوق، وثلاث خلفيات إجرائية أصلية برخصة MIT. ويمكن إضافة صور تملك حق استخدامها.
راجع [تصحيح المطابقة البصرية والفروق المتبقية](docs/VISUAL-PARITY.md) و[حقوق الصور وأصحابها](THIRD-PARTY-NOTICES.md#photographic-cinematic-wallpapers-visual-parity-update).

الحزمة مستقلة: `io.github.mansouralotaibi.ufuq`.
لا تغيّر أدوات البناء المشغّل الافتراضي ولا تعطل تطبيقات الجهاز.
تعمل لوحة الشبكة الأصلية حتى API 28 بعد موافقة المستخدم على الصلاحية اللازمة، وتستخدم الإصدارات الأحدث إعدادات النظام.
تعمل بيانات كرة القدم النصية من TheSportsDB مع توثيق شروط المزود.

راجع [البناء](BUILDING.md)، [التثبيت الآمن](INSTALLATION.md)،
[التوافق](COMPATIBILITY.md)، [الخصوصية](PRIVACY.md)، و[التراخيص](THIRD-PARTY-NOTICES.md).
تم تنفيذ اختبارات محاكاة إطار أندرويد على API 19 و28 و34، وهي لا تعادل اختبار تلفزيون أو محاكي فعلي.

تعمل التأملات اليومية دون اتصال: أربع آيات كاملة من Tanzil وثلاثة مقتطفات حديث من ويكي مصدر العربية،
مع روابط المصادر والتراخيص داخل تفاصيل النص. لا يُعاد ترخيص هذه البيانات برخصة MIT.
راجع [مقارنة الميزات](docs/FEATURE-PARITY.md) و[إشعارات الأطراف الثالثة](THIRD-PARTY-NOTICES.md).

راجع [مصفوفة المطابقة الوظيفية والاستقرار](docs/FUNCTIONAL-PARITY.md) للفروق عن المصدر الأصلي، والإصلاحات، وأدلة الاختبار الفعلي، والحدود التي لم تُتحقق بعد.

يتيح «نوع الخط» الخط الافتراضي المعتمد أو أميري للعربية، والخط الافتراضي أو Lato للإنجليزية، مع حفظ مستقل لكل لغة. تبقى طباعة الساعة والنصوص الدينية مخصصة لغرضها. الخطوط الإضافية ثابتة ومرخصة وفق SIL OFL 1.1؛ راجع [توثيق المصادر](third_party/ui-font-provenance.json).
